# デザインとスタイルガイド

## デザインコンセプト
**「The Conductor」- 明晰なる調和**

ARCHAIVEが、社内に散在する複雑な情報を「指揮（conduct）」し、一つのスムーズで調和の取れた「流れ」に変えていく、プロフェッショナルなパートナーであることを表現します。

### キーワード
- **明晰性**
- **先進性**
- **信頼**

## カラーパレット

### メインカラー
- **カラーコード:** #37B7C4 (Teal Blue)
- **狙い:** 明晰性、技術革新、スムーズな流れ
- **意味:** ARCHAIVEがもたらす情報の「透明性」と「先進的な技術力」を象徴。複雑な問題をクリアにし、淀みない業務プロセスを実現する価値を表現

### ベースカラー
- **カラーコード:** #FFFFFF (White)
- **狙い:** 清潔感、クリーンさ、無限の可能性
- **意味:** メインカラーの鮮やかさを最大限に引き立て、LP全体にクリーンでモダンな印象を与える。コンテンツの可読性を最高レベルに保つ

### テキストカラー
- **カラーコード:** #333333 (ダークグレー)
- **狙い:** 可読性、誠実さ、落ち着き
- **意味:** 真っ黒（#000000）ではなく、少し柔らかいダークグレーを使用。長文でも目に優しく、洗練された印象を与える

### アクセントカラー
- **カラーコード:** #f54848 (Vivid Red)
- **狙い:** 重要性、注目、行動の起点
- **意味:** ユーザーの注意を最も重要な情報やアクションに引きつける。戦略的かつ限定的に使用

## タイポグラフィ
- **フォント:** Noto Sans JP
- **特徴:** 信頼性、可読性、調和
- **理由:** 誰にでも読みやすく、あらゆるデバイスで美しく表示される。クリーンでモダンなデザインコンセプト全体と調和

## ビジュアル方針
- 情報の「流れ」や「繋がり」を可視化する、抽象的なCGグラフィック
- メインカラーを基調とした、シンプルな線画イラスト
- 実際のUI画面のクリーンなスクリーンショット

### ビジュアルのキーワード
- **インテリジェンス**
- **整理**
- **具体性**

## 色の使用指針

### ヒーローセクション
- **見出し:** メインカラー（#37B7C4）

### CTAボタン
- **メインCTA:** メインカラー（#37B7C4）
- **サブCTA:** メインカラー（#37B7C4）の枠線＋白背景

### 限定的なハイライト
- **特別強調:** アクセントカラー（#f54848）を「無料」などの特に強調したい文言に限定使用
